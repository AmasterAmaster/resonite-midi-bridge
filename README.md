# Resonite MIDI Bridge

A C# application that connects MIDI devices to Resonite using WebSockets.

## Goals

- MIDI Note Input
- MIDI Output
- Control Change Support
- Tempo Synchronization
- DAW Integration
- Multiple Device Support

## Technology

- C#
- .NET
- DryWetMIDI
- WebSockets
- Resonite
